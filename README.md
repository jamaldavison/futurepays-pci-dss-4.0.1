# FuturePays — PCI DSS v4.0.1 Compliance & Audit Readiness

## Project Overview
FuturePays is a fictional e-commerce business used to demonstrate PCI DSS v4.0.1 security assessment and audit-readiness practices.

This portfolio project focuses on payment data flows, PCI DSS scoping, security controls, audit evidence, and remediation planning.

## Business Scenario
FuturePays operates an online retail store using a third-party hosted payment provider. The proposed architecture separates card data collection from the FuturePays order system.
