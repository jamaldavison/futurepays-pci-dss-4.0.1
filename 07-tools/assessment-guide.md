# Reviewer Playbook

1. Confirm business, payment processing, and system-owner interviews.
2. Validate diagram and inventory with technical observation.
3. Determine relevant PCI DSS v4.0.1 requirements and SAQ eligibility, without pre-judging.
4. Define control owner, evidence owner, testing period, sample population, and acceptance criteria.
5. Obtain sensitive evidence only through approved secure storage.
6. Test controls and document source artifacts, timestamps, observations, exceptions and sign-off.
7. Issue findings only when supported by evidence; define remediation and independent retest.
8. Verify TPSP compliance evidence, responsibilities and applicable external scanning.
9. Sanitize public portfolio deliverables; keep real customer/system data private.

Official PCI SSC: https://www.pcisecuritystandards.org/document_library/
